KT-Bus browser relay

Current relay runtime: v0.8.0+

The installed userscript is now a small version-checking bootstrap. On each ChatGPT page load it fetches the current relay runtime with cache busting, rejects runtimes older than v0.8.0, and falls back only to a previously validated v0.8+ cache.

The bootstrap has no authority to open visible helper tabs. The v0.8 relay supports guarded localhost status checks, exactly-once request claims, bounded schedules, and invisible cross-chat delivery.

Install or update the KT-Bus relay bootstrap

Upgrading from v0.7: use the install/update link once, accept the userscript-manager update, then reload the ChatGPT tab. Existing v0.7 JavaScript already running in a tab cannot replace itself in place.

After reload, verify with KTBUS_POC_REQUEST {"id":"relay-version-check","op":"hello"}. The result should report "version":"0.8.0" or newer.
