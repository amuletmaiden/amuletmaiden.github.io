KT-Bus browser relay POC

This is a deliberately harmless proof of concept. It lets an explicit assistant message ask the browser to read only http://127.0.0.1:8765/api/status, then posts the status back into the same ChatGPT conversation.

It cannot read files, run commands, browse, or write anything.

Install the ping-only userscript

After installation, reload the ChatGPT tab. The test marker is KTBUS_POC_REQUEST {"id":"...","op":"ping"}.
