DAT direct HTTP prototype

This userscript lets Browser ChatGPT call the DAT helper directly on 127.0.0.1:8765, bypassing GitHub for command transport.

It supports one call or a batch of up to 64 local DAT operations per ChatGPT round trip. The local helper remains responsible for filesystem/write/exec policy.
