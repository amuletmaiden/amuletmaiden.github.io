Stacks

A portable personal-library shell for humans and agents. One Python file, standard library only: no extension, Node, database, account, or kt-bus installation.

Get the toolAgent notes
Human interface
python katherines_stacks.py serve

Starts the Stacks UI at 127.0.0.1:8765.

Agent interface
python katherines_stacks.py search "book title"
python katherines_stacks.py book <record-id>
python katherines_stacks.py options <record-id>

Each command returns JSON. Agents can also call /api/search, /api/book/<id>, and /api/options/<id> over localhost.

Designed for discretion

Stacks separates discovery, record inspection, and acquisition choices. The caller sees the evidence first and decides what to do with it instead of the tool silently choosing files.
