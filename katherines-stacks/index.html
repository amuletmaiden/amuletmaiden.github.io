For humans
1. Download the Stacks launcher.
2. Double-click it.
3. Your browser opens Katherine's Stacks. Search normally.

No terminal or command line is part of the human workflow. The launcher is windowless and loads the current Stacks core automatically.

For chatbots

The portable core exposes structured search, record inspection, and acquisition-option endpoints over localhost. See Agent notes for the API contract.

Designed for discretion

Stacks separates discovery, record inspection, and acquisition choices so the caller can judge a record before following an option.
